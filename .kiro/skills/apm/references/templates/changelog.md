# Changelog

本文件记录版本间的用户可见变更。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---

## 格式约定

- 所有版本统一使用 `##` 标题：`## [x.y.z] - YYYY-MM-DD`
- major 版本前加 `---` 分隔线，形成视觉断层
- 分类标签（Added / Changed / Fixed / Breaking）使用粗体，不占标题层级

示例：

```markdown
## [Unreleased]

**Added**

- ...

---

## [2.0.0] - 2026-05-18

**Breaking**

- 不兼容变更描述。

**Added**

- 新功能描述。

## [1.3.0] - 2026-05-10

**Added**

- 新功能描述。

**Changed**

- 变更描述。

## [1.2.1] - 2026-05-05

**Fixed**

- 修复描述。
```
