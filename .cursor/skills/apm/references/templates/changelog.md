# Changelog

本文件记录版本间的用户可见变更。

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

---

## 标题层级约定

| 版本类型 | 标题层级 | 示例 |
|----------|----------|------|
| major | `##` | `## [2.0.0] - 2026-05-18` |
| minor | `###` | `### [0.7.0] - 2026-05-18` |
| patch | `####` | `#### [0.6.4] - 2026-05-18` |

分类标签（Added / Changed / Fixed / Breaking）使用粗体行内标记，不占用标题层级：

```markdown
## [2.0.0] - 2026-05-18

**Breaking**

- 描述不兼容变更。

**Added**

- 描述新功能。

### [0.7.0] - 2026-05-18

**Added**

- 描述新功能。

**Changed**

- 描述变更。

#### [0.6.4] - 2026-05-18

**Fixed**

- 描述修复。
```
